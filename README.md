# PL

учебное пространство по предмету **языки программирования**. СПбПУ Петра Великого.

сквозная тема курса — **оптимизация**: как оптимизирует компилятор, как оптимизировать
алгоритм и код, как считать на GPU, как профилировать и ускорять свою программу.
задача здесь — понять предмет и сдать лабы с курсовой.

## структура

```
материалы/                    материалы препода КАК ЕСТЬ — не редактируются
  OPTBENCH.c                  исходник на Си для ЛР-1
  metal_demo.tar.gz           демо для ЛР-3 (GPU / Metal)
  Требования лабораторная №1…3.docx, Курсовая.docx

knowledge-base/               конспекты СВОИМИ СЛОВАМИ
  _index.md                   карта тем
  00-progress.md              трекер — что сделано, где я сейчас
  journal.md                  журнал по сессиям
  NN-*.md                     конспекты по темам

labs/                         лабораторные
  Лабораторная работа №N/     итоговый .docx, листинги, plan.md, otchet.md, zashchita.md
```

## что в курсе

| Работа | Тема | Коротко |
|--------|------|---------|
| ЛР-1 | оптимизирующие компиляторы | компилируем `OPTBENCH.c` без оптимизаций и с ними, сравниваем ассемблерные листинги по каждому блоку, плюс оптимизация по размеру |
| ЛР-2 | оптимизация алгоритма | решатель числовых ребусов (`SEND+MORE=MONEY`), оптимизации отдельными коммитами на GitHub, замер скорости |
| ЛР-3 | вычисления на GPU | CUDA / OpenCL / Metal, задача линейной алгебры или брутфорс хэша, CPU vs GPU, графики |
| Курсовая | оптимизация своей программы | профилирование, оценка сложности, алгоритмическая + машинно-независимые оптимизации |

## принцип

предмет идём **по пунктам методички**, теорию объясняем по ходу и простым языком,
привязанную к тому, что реально видно в листинге или в замерах. команды в основном
запускает пользователь у себя (это идёт в отчёт), Claude ведёт, объясняет и сверяет.

онлайн-компиляторы методичкой запрещены — вся компиляция локальная.

## Факты, которые легко забыть

- **Первый `gcc` в PATH — это clang** (llvm-mingw). Настоящий GCC — `C:\mingw64\bin\gcc.exe`.
- Моя (Claude) компиляция требует `dangerouslyDisableSandbox` + `PATH=/c/mingw64/bin`,
  иначе `cc1.exe` не стартует. На машине пользователя gcc работает как обычно.
- Онлайн-компиляторы **запрещены** методичкой.
- Пользователь запускает команды у себя в обычном терминале, не через `!` Claude Code.
